The Neural Network Verification Problem aims to determine the minimum adversarial distortion required to fool a pre-trained multi-layer perceptron (MLP) classifier. Given a correctly classified input sample $x_0 \in [0,1]^{n_{\text{in}}}$ with true label $\lambda$, the goal is to find a perturbed input $x' \in [0,1]^{n_{\text{in}}}$ that causes the network to predict a specified target label $\mu \neq \lambda$, while minimizing the $\ell_1$ distance between $x'$ and $x_0$.
The network consists of $L$ layers, where each hidden layer $k \in \{1, \ldots, L-1\}$ applies an affine transformation followed by a ReLU activation, and the output layer $L$ applies an affine transformation only. Let $z^{(0)} = x'$. For each layer $k$ with weight matrix $W^{(k)}$ and bias vector $b^{(k)}$, the pre-activation value of neuron $j$ is defined as $\hat{z}_j^{(k)} = W^{(k)}_{j,:} z^{(k-1)} + b^{(k)}_j$, i.e., the inner product of the $j$-th row of $W^{(k)}$ with the previous layer's output, plus the corresponding bias. The post-activation output is $z_j^{(k)} = \max(\hat{z}_j^{(k)}, 0)$ for hidden layers and $z_j^{(L)} = \hat{z}_j^{(L)}$ for the output layer. Each hidden neuron introduces a binary variable $a_j^{(k)} \in \{0, 1\}$ to encode the ReLU switching behavior exactly.
The adversarial condition requires that the output logit of the target label $\mu$ is no less than that of the true label $\lambda$, i.e., $\hat{z}_\mu^{(L)} \geq \hat{z}_\lambda^{(L)}$. The objective is to minimize the $\ell_1$ distortion $\sum_i |x'_i - x_{0,i}|$, linearized via auxiliary variables $d_i \geq |x'_i - x_{0,i}|$.
