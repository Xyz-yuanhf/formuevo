The IMO 2025 Problem 6 asks to cover an $N \times N$ grid of unit squares with axis-aligned rectangular tiles, such that no tiles overlap, and exactly one unit square remains uncovered (a "hole") in each row and each column. The objective is to minimize the total number of rectangular tiles used to cover the rest of the grid. 
To formulate this as a Mixed-Integer Linear Program (MILP), the problem can be modeled by defining fixed-length horizontal strips (intervals) and tracking their vertical continuation over the 2D board. Let $R = \{1, \dots, N\}$ and $C = \{1, \dots, N\}$ be the row and column indices. We define a set of all contiguous column intervals $I = \{(a, b) \in C \times C \mid a \le b\}$. A rectangular tile is formed by a sequence of identical active horizontal intervals across adjacent rows. 
The decision variables include: the position of the holes, whether a specific horizontal interval $(a, b)$ is active on a given row, and "start" / "end" flag variables to track when a vertical strip of intervals begins and ends. The objective is to minimize the sum of all "start" flags, which exactly corresponds to the total number of rectangles used. The constraints enforce that each row and column has exactly one hole, every cell is covered either by a hole or exactly one active interval, and flow-balance equations ensure that the start, continuation, and end of rectangles are logically consistent across adjacent rows.
