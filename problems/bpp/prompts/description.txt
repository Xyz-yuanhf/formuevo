The 1D Bin Packing Problem aims to determine the optimal assignment of a set of $n$ discrete items into a set of identical bins. Each bin is homogeneous and possesses a fixed, deterministic maximum weight capacity $W$. Each item $i$ has a predefined specific size or weight $w_i$. We explicitly assume that all item weights and the bin capacity are discrete (positive integers), where pseudo-polynomial arc-flow formulation can be applied.
The packing decision involves determining exactly which bin each item is placed into. Every item must be assigned to exactly one bin, and splitting an item across multiple bins is strictly prohibited. For any bin that is utilized, the cumulative weight of all items assigned to it must satisfy the physical capacity constraint, meaning it cannot exceed $W$. Sufficient bins are assumed to be available, bounded by a maximum possible number $m$ (typically $m=n$).
The objective is to minimize the total number of bins actively utilized to successfully accommodate all $n$ items.
